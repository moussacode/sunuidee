# 💡 SunuIdée

SunuIdée est une application web permettant de gérer, organiser et filtrer des idées de projets.

Les utilisateurs peuvent :

- ➕ Ajouter une idée
- ✏️ Modifier une idée existante
- 🗑️ Supprimer une idée
- 🗑️ Supprimer toutes les idées
- 🏷️ Filtrer les idées par catégorie
- 💾 Sauvegarder automatiquement les données dans le Local Storage
- 🔔 Recevoir des notifications animées grâce à GSAP

---

## 🚀 Technologies utilisées

- HTML5
- Tailwind CSS
- JavaScript (Vanilla JS)
- GSAP (animations)
- Local Storage

---

## 📸 Fonctionnalités

### Gestion des idées

Chaque idée contient :

- Un titre
- Une description
- Une catégorie

---

### Filtres dynamiques

Les idées peuvent être filtrées par catégorie :

- Toutes
- Technologie
- Business
- Pédagogie
- Autres catégories

Plusieurs filtres peuvent être sélectionnés simultanément.

---

### Notifications

L'application affiche des notifications animées pour :

- Ajout d'une idée
- Modification d'une idée
- Suppression d'une idée
- Suppression de toutes les idées
- Erreurs ou avertissements

---

### Sauvegarde locale

Toutes les idées sont automatiquement enregistrées dans le navigateur grâce au Local Storage.

Les données restent disponibles même après un rechargement de la page.

---

## 🎨 Animations GSAP

Les animations suivantes ont été implémentées :

### Modal

- Apparition avec effet zoom
- Effet de rebond (`back.out`)

### Toasts

- Apparition depuis la droite
- Disparition automatique avec fade out
